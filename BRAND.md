# Política de marca do BoardStar

## Independência

BoardStar é um projeto independente. O uso do GitHub para hospedar código ou acompanhar contribuições não significa parceria, endosso ou vínculo com o GitHub.

Não use nomes, logotipos ou elementos visuais de terceiros de forma que sugira autorização ou associação inexistente. O nome de uma empresa ou instituição só pode aparecer como parceira, anfitriã, mantenedora ou cliente com autorização expressa.

## Uso permitido

É permitido mencionar o BoardStar de forma factual, por exemplo: “compatível com o BoardStar” ou “código hospedado no GitHub”, desde que não haja confusão sobre origem ou endosso.

## Uso que exige autorização

Solicite autorização antes de usar a marca BoardStar em produto comercial, selo, domínio, campanha, certificado, parceria anunciada ou material que sugira aprovação oficial.

A Apache License 2.0 do código não concede licença para usar a marca, o nome ou o logotipo BoardStar.
